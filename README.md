# SPADA: Software Platform for Aggregation of Data and Analysis

SPADA is a low-code development platform designed for data aggregation, processing, and analysis preparation. It helps automate, streamline, and visualize info within an educational, research, and startup projects. The platform is tailored for students, postgraduates, professionals, and domain researchers.

To minimize the coding burden, SPADA requires no actual algorithmic or object-oriented programming. Instead, it provides a flexible environment focused on user interface and database design.

To begin designing your user interface, please refer to our **Wiki**. It contains a simplified guide to YAML syntax. For a deeper understanding and code validation, follow the links to the full reference documentation.

### Key Advantages

* **Low-Code Development**: Features a low entry barrier. No prior coding experience is required—only a basic knowledge of YAML.
* **Offline Readiness**: Runs fully locally with no internet access needed, making it ideal for field engineers.
* **Zero Configuration**: Uses pre-configured & hardcoded defaults to eliminate installation, setup, and startup issues.
* **YAML-Based**: Avoids complex DSLs or traditional programming languages to ensure a fast start.
* **Multiplatform Binaries**: Released as a single executable for multiple OS platforms with all libraries bundled in.
* **Ready-to-Use Examples**: Includes pre-made YAML templates to simplify your workflow.
